# Central de Gestão de Fretes — pacote de integração

## Comece por aqui

1. Leia `GUIA_INSTALACAO_PASSO_A_PASSO.md` na íntegra.
2. Leia `STATUS_IMPLEMENTACAO.md` para distinguir implementação de homologação.
3. O backend Apps Script está em `backend-apps-script/Code.gs`.
4. A URL do Apps Script e o token devem ser configurados apenas como variáveis de ambiente do servidor.
5. Faça primeiro a instalação em Preview e use uma cópia da planilha para homologação.

**Estado atual:** a integração está implementada no código, mas não foi validada contra a planilha/implantação real. A instalação das dependências e o build excederam o limite de tempo deste ambiente. Não tratar como pronta para produção até concluir a lista de homologação.
